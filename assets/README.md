# 🎨 Reference art

The approved scenes, drawn by the [Python prototype](../prototype). Open any `.svg` in your browser to
watch it burn; each folder also has a `preview.png` with every state stacked.

Every SVG here is regenerated by `python3 prototype/generate_all.py`, and a clean run produces no diff.
Don't edit them by hand: change the prototype instead.

## Themes

| Theme | ASHEN · 0 days | KINDLED · 1–3 | BLAZING · 4–14 | ETERNAL · 15+ |
| --- | --- | --- | --- | --- |
| [`ruins`](ruins) (default) | ✅ 24 KB | ✅ 34 KB | ✅ 46 KB | ✅ 66 KB |

| [`cathedral`](cathedral) | ✅ 102 KB | ✏️ to design ([#15]) | ✅ 126 KB | ✅ 151 KB |

The size budget is **100 KB per SVG**. `cathedral` is over it today and has to be slimmed down in the
port ([#15]).

The sketches were rendered with fixed sample data: streak 0, 2, 9 and 23, with 0, 5, 23 and 41
contributions in the last week.
